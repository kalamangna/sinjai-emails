Panduan Integrasi API TTE BSrE

Akses Server Tanda Tangan Elektronik via Reverse Proxy Publik Pemkab Sinjai

Informasi Koneksi:
• Base URL Akses Publik: http://apl.sinjaikab.go.id/tte/
• Server Backend Lokal: http://10.91.162.6/
• Metode Autentikasi: HTTP Basic Authentication (Username & Password Client Service)

1. Mekanisme Autentikasi

Setiap request ke endpoint API TTE wajib menyertakan header Authorization: Basic <credentials>, di mana credentials adalah hasil enkripsi Base64 dari username:password sistem eSign instansi.

Authorization: Basic dXNlcm5hbWU6cGFzc3dvcmQ=

2. Daftar Endpoint Utama

A. Cek Status Layanan

GET /api/status

Digunakan untuk memeriksa apakah modul eSign Client Service aktif dan dapat berkomunikasi dengan server BSrE BSSN.

B. Cek Status Sertifikat User

GET /api/user/status/{nik}

Memeriksa apakah pemilik NIK memiliki sertifikat elektronik yang aktif.

C. Penandatanganan Dokumen PDF

POST /api/sign/pdf

Content-Type: multipart/form-data

Field Tipe Deskripsi
file File (Binary) File PDF yang akan ditandatangani.
nik String 16 digit NIK penandatangan.
passphrase String Kata sandi / passphrase sertifikat BSrE penandatangan.
tampilan String visible (ada visualisasi QR) atau invisible.
halaman String / Integer Nomor halaman tempat tanda tangan ditempatkan (misal: 1 atau terakhir).
xAxis Float Koordinat horizontal (X) posisi tanda tangan.
yAxis Float Koordinat vertikal (Y) posisi tanda tangan.
width Float Lebar visual QR code / spesimen (standar: 100 - 150).
height Float Tinggi visual QR code / spesimen (standar: 100 - 150).

Response Sukses: HTTP 200 dengan Content-Type application/pdf (file PDF hasil tanda tangan).

D. Verifikasi Dokumen PDF

POST /api/sign/verify

Content-Type: multipart/form-data

Field Tipe Deskripsi
file File (Binary) File PDF yang ingin diverifikasi keasliannya.

3. Contoh Kode Implementasi

Contoh 1: Menggunakan cURL (Bash)

# 1. Cek Status Service
curl -X GET "http://apl.sinjaikab.go.id/tte/api/status" \
     -u "username:password"

# 2. Tanda Tangani Dokumen PDF
curl -X POST "http://apl.sinjaikab.go.id/tte/api/sign/pdf" \
     -u "username:password" \
     -F "file=@/path/to/dokumen.pdf" \
     -F "nik=730XXXXXXXXXXXXX" \
     -F "passphrase=Rahasia123!" \
     -F "tampilan=visible" \
     -F "halaman=1" \
     -F "xAxis=100" \
     -F "yAxis=100" \
     -F "width=120" \
     -F "height=120" \
     --output "dokumen_signed.pdf"

Contoh 2: Menggunakan PHP (cURL Native)

<?php
$url = 'http://apl.sinjaikab.go.id/tte/api/sign/pdf';
$username = 'username_tte';
$password = 'password_tte';

$postData = [
    'file'       => new CURLFile('/path/ke/surat.pdf', 'application/pdf', 'surat.pdf'),
    'nik'        => '730XXXXXXXXXXXXX',
    'passphrase' => 'PasswordTTE123',
    'tampilan'   => 'visible',
    'halaman'    => '1',
    'xAxis'      => '100',
    'yAxis'      => '150',
    'width'      => '120',
    'height'     => '120',
];

$ch = curl_init();
curl_setopt($ch, CURLOPT_URL, $url);
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
curl_setopt($ch, CURLOPT_POST, true);
curl_setopt($ch, CURLOPT_POSTFIELDS, $postData);
curl_setopt($ch, CURLOPT_HTTPAUTH, CURLAUTH_BASIC);
curl_setopt($ch, CURLOPT_USERPWD, "$username:$password");
curl_setopt($ch, CURLOPT_TIMEOUT, 120); // Beri timeout cukup lama

$response = curl_exec($ch);
$httpCode = curl_getinfo($ch, CURLINFO_HTTP_CODE);
curl_close($ch);

if ($httpCode === 200) {
    file_put_contents('/path/ke/surat_signed.pdf', $response);
    echo "Dokumen berhasil ditandatangani!";
} else {
    echo "Gagal menandatangani. Error response: " . $response;
}
?>

Contoh 3: Menggunakan Python (Requests)

import requests
from requests.auth import HTTPBasicAuth

url = "http://apl.sinjaikab.go.id/tte/api/sign/pdf"
auth = HTTPBasicAuth("username_tte", "password_tte")

files = {
    'file': ('surat.pdf', open('/path/ke/surat.pdf', 'rb'), 'application/pdf')
}

data = {
    'nik': '730XXXXXXXXXXXXX',
    'passphrase': 'PasswordTTE123',
    'tampilan': 'visible',
    'halaman': '1',
    'xAxis': '100',
    'yAxis': '100',
    'width': '120',
    'height': '120'
}

response = requests.post(url, auth=auth, files=files, data=data, timeout=120)

if response.status_code == 200:
    with open('/path/ke/surat_signed.pdf', 'wb') as f:
        f.write(response.content)
    print("PDF Berhasil ditandatangani!")
else:
    print(f"Gagal ({response.status_code}): {response.text}")

4. Catatan Penting & Troubleshooting

Perhatikan Saat Deploy Production:
1. Timeout: Komunikasi antara server lokal ke BSSN pusat membutuhkan waktu beberapa detik. Pastikan script pemanggil mengaktifkan timeout minimal 60 - 120 detik.
2. Error 401 Unauthorized: Periksa kembali username dan password Basic Auth yang didaftarkan pada eSign Client Service.
3. Ukuran Berkas: Pastikan ukuran PDF tidak melebihi batasan sistem lokal maupun BSSN (disarankan di bawah 20MB).
